# Lacunes du référentiel suisse

Notions au programme du CO genevois (PER, prescriptions cantonales,
indications pédagogiques) pour lesquelles MathALÉA n'a pas d'exercice, ou pas
assez. Créer les exercices manquants, puis les classer avec ce skill et
retirer le point.

Format : année, section, notion (intitulé officiel), constat, feuille prévue.

## Catégories en attente d'exercices

Les emplacements ci-dessous suivent l'ordre des moyens d'enseignement et la
structure du CO. Les codes sont réservés dans cette documentation : créer
une feuille dans le menu lorsqu'un exercice adapté peut l'alimenter. Les
mentions « sensibilisation » sont conservées dans les titres des chapitres
concernés ; « (s) » dans la colonne Sections rappelle cette distinction.

## Réglages par section

Exercices conservés parce qu'un réglage existant permet de choisir les cas
adaptés. L'enseignant sélectionne ces réglages dans le formulaire de
l'exercice. Le classement dans une feuille du menu ne les impose pas et ne
change pas les valeurs par défaut communes aux autres référentiels.

Les paramètres `s`, `s2`, etc. correspondent à `sup`, `sup2`, etc. Les
numéros de cas sont ceux affichés dans le formulaire ; pour un formulaire
texte, les tirets permettent de sélectionner plusieurs cas.

Les représentants issus de la déduplication, les variantes couvertes et les
réglages à reprendre sont détaillés dans
[doublons-co.md](doublons-co.md#représentants-et-variantes-entièrement-couvertes).
Le représentant peut désormais être utilisé dans plusieurs feuilles : y
sélectionner les types correspondant au savoir-faire de la feuille.

| Exercice | Feuilles | Réglage pour la section |
|---|---|---|
| 5G2E-5 | 9e GM2E | types 1 à 3 (sans disque) |
| 11GM2-4 | 9e GM3B | types 1 et 2 (cube, pavé) |
| 6M1autoE-2 | 9e GM1A | sans le cercle |
| 3G10-1 | 10e ES2B | types 1 à 4 (sans homothétie) |
| 4C30-2 | 10e NO4C | selon la section |
| 1mCN4 | 9e NO4F | Période d'un chiffre, sans décimale hors période. Ces réglages ne limitent pas aux tiers : classement provisoire, à remplacer par l'exercice ciblé décrit plus haut. |
| 4C32 | 10CT NO5A, 11CT NO3A | Difficulté « Facile » (`s2=1`) ; nombres négatifs décochés (`s3=false`). Les deux sens de conversion restent possibles. |
| 4C32-3 | 10LC/LS NO5B | Type 1 (`s=1`), conversions d'unités de stockage et calculs ordinaires. Les autres cas faisant intervenir des opérations en notation scientifique ne sont pas à sélectionner en 10e. |
| 3L15 | 10LC/LS FA5E, 11CT/LC FA4H | Type 4 (`s=4`), équations de la forme ax²=b. La correction utilise la factorisation. |
| 3L15 | 11LS FA4C | Types 6 et 7 (`s=6-7`), où les termes de degré 2 s'éliminent. Les autres cas restent accessibles dans le chapitre du second degré. |
| 3L11-13 | 11CT FA3E | Coefficients entiers (`s2=1`), degré maximum 1 (`s3=1`), une variable (`s4=1`). |
| 3L11-11, 3L11-12, 3L11-13 | 10LC/LS et 11LC, feuilles de calcul littéral | Choisir des coefficients entiers et borner le degré et le nombre de variables selon le contenu de la feuille. |
| 3L10 | 11CT FA3E | Types 1, 2, 5 et 6 (`s=1-2-5-6`), sans terme de degré 2. |
| 3L11-2 | 11CT FA3E | Types 1, 2, 4, 5, 6, 7 et 8 (`s3=1-2-4-5-6-7-8`), sans terme ni produit de degré 2. |

restent uniquement en 11LS dans le CO ; les exercices imposant des exposants
négatifs quittent les feuilles CT concernées ; 2F21-7, qui demande toujours
un tableau de signes, quitte le CO. Leurs classements dans les autres
référentiels sont conservés.

Les opérations avec la notation scientifique relèvent de la 11e LS, même
avec des exposants positifs : 11NO3A-2 et 4C32-4 sont classés en
`11LSNO3A`, sans réglage particulier à imposer. Le profil précédemment
proposé pour 11NO3A-2 en CT est retiré.

## Préqualifiant

Plan d'études cadre du Préqualifiant (2026-2029), feuilles `PRQ…`. Niveau :
N1 AFP, N2 CFC à exigences moyennes, N3 CFC à exigences élevées. Les
exercices de lycée sont exclus (trop lourds) : une notion couverte seulement
au lycée compte comme lacune.
